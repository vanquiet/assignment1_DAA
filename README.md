## Overview
Implementation and performance analysis of divide-and-conquer algorithms in Java:
- **MergeSort** (with reusable auxiliary buffer)
- **QuickSort** (random pivot + 3-way partition)
- **QuickSelect** ($O(n)$ average rank selection)
- **InsertionSort** (cutoff for small arrays $n \le 15$)

## Structure
- `src/` — Source code and unit tests
- `REPORT.md` — Complexity proofs, Master Theorem, and conclusions
- `results.csv` — Raw benchmark data
- `*.png` — Time, depth, and ratio plots
